# Regra do hifen curto

Regra fixa do dono (2026-09-09) para este projeto e para todos os projetos.

- Nunca usar hifen longo (em dash, U+2014).
- Usar sempre hifen simples ("-") em conteudo do projeto: documentacao, planos,
  checklist, interface operacional, mensagens renderizadas, commits e respostas.
- Normalizar documentos existentes que ainda usem hifen longo antes de continuar
  a execucao, preservando conteudo e historico.
